cosinus os is an operating system focused on **modern solutions** such as a micro kernel which is the main presentation center.The project includes an extensive userspace system with a new approach to user safety.has been developed in an open form since February 14, 2026, previously it was developed in a closed form since December 18, 2025 .

## plans for cosinus os 
I plan to improve the management of my ecosystem and the system 

presenting a new form of protection against viruses

presenting the world of operating systems with new ideas to implement or old ones from a different angle 

## openness of the system 
in this system, I create a new system for versioning and publishing applications in an easier form and more convenient work when managing specific applications.

The system can also be folked, it is released under the mit license, so anyone who has an idea for changes can create their own or write to me and maybe it will be released as an official news.
